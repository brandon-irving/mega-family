# First UI/UX UAT implementation

October 30, 2026. Changes are in the existing working tree, alongside the earlier performance audit and UI redesign. The development backend was updated; production was not deployed.

## Changes

| Area | Result |
| --- | --- |
| Modal navigation | Rapid duplicate opens and closes are suppressed. Closing a route checks for a usable back destination. Calendar, Lists, and member profiles now belong to the root modal stack, outside the tab navigator. |
| Keyboard | Scrolling dismisses the keyboard throughout the shared screens, sheets, chat lists, and other scroll surfaces. Bottom-sheet dismissal drags belong to the header/grip, so scrolling content does not dismiss the sheet. |
| HQ | A separate close control sits above the panel content. Tapping outside dismisses it. Panel content scrolls within the room instead of clipping its action. Titles are smaller. Idle MEGAs wander; hidden rooms and reduced-motion preferences stop idle movement. |
| Chat | A single compact composer contains the plus, text, and mic/send controls. Typed lines grow the field. A chevron appears when reading older messages and returns to the latest message. Shared card titles are smaller. |
| Attachments | Plus opens Camera, Photos, and Files. Selected files have a preview/confirmation step and a 10 MB limit. File links resolve through the message's thread access rules. Failed sends reuse their upload. Browser file URLs are released on close, success, oversized selection, and unmount. |
| Ideas | Removed the introductory subtitle and category pill strip. A filter/sort sheet retains All/Saved, category, and Newest/Oldest selections. Chronological sorting happens before server pagination; text searches retain relevance ordering. Card titles are smaller. |
| Talk | Hold to speak, release to send automatically. Audio leaves recording mode and plays through the speaker, including silent mode. The working state is visible, the sprite is smaller, and the microphone is a drawn icon. A first-use guide explains holding, releasing, and locking. The last user words are truncated visually; the latest reply remains available to read. The processing label is **Just a moment…**, following the user's feedback. |
| Family | Lists and Places share the first row. Calendar fills the next row and shows the next visible event. Removed the Ideas shortcut. Message dismisses the profile and selects Chat. A parent's read-only child conversation has a separate bounded viewport outside the profile ScrollView. |
| Today | Compact date/status, decisions needing answers, agenda rows, and lists. Calendar/Lists open above Today and return to it on close. Informational notes have a distinct label and no answer buttons. Only current, non-actionable tips/updates qualify as informational notes. Actionable suggestions delivered quietly still retain their answer UI. |

The room editor remains deferred as requested. Idle conversation between MEGAs was optional; this pass implements walking.

## Follow-up: smooth HQ walking

The user noticed that HQ walking was choppier than sign-in. Both already used `MegaSprite`, but HQ directly changed absolute layout coordinates by one tile every 260 ms. Sign-in used Reanimated linear interpolation between its engine positions.

`HqWalker` now interpolates the sprite wrapper and its tap target using that same `withTiming`/linear approach. Tile routing, obstacle avoidance, and the existing coarse room update rate remain intact. Unchanged coordinates do not restart animations. Reduced motion, hiding the room, resizing, and unmounting cancel or snap the animation as appropriate. No dependency or native rebuild is needed for this follow-up.

Validation: 21 tests across five HQ/walker suites passed, including continuous-animation scheduling, unchanged-target behavior, cancellation, timer stability, and no idle room commits after arrival. Typecheck passed. A 393 × 852 browser preview produced intermediate vertical positions such as 255.748, 258.191, 260.371, and 262.829 between tile updates, confirming interpolation in the running app. The MEGA detail panel still opened correctly. This is browser evidence, not an iPhone frame-rate measurement. [Preview](./hq-smooth-walking.png).

API references: [Expo SDK 58 Reanimated](https://docs.expo.dev/versions/v58.0.0/sdk/reanimated/), [withTiming](https://docs.swmansion.com/react-native-reanimated/docs/animations/withTiming/), [cancelAnimation](https://docs.swmansion.com/react-native-reanimated/docs/core/cancelAnimation/).


## Gift ideas follow-up

The gift detail was dropping the selected source index, opening the entire gift set in its original order. It now passes the original index through to GiftsCard, shows that gift first without the redundant outer ThreadCard, and keeps other gifts collapsed under “Other gift ideas”. Add-to-list and price-watch actions retain their original indexes. Each idea renders only the shared facts cited by its own basedOn indexes, inside its own card.

ModalSheet previously reserved safe-area padding outside its scrollable body and inherited the presenting screen’s insets. It now measures the native modal window with a separate SafeAreaProvider, keeps bottom spacing inside the scrolling content, explicitly bounds the scrolling body, and disables automatic iOS content-inset adjustment. The fixed header cannot shrink. On web it uses the existing context: a nested provider inside the portal measured an entire viewport as a bottom inset during verification, so the native provider is platform-specific. Short sheets fit their content.

Verification: all 850 frontend tests across 122 suites passed. Coverage includes opening a non-first gift, revealing other gifts, correct add/watch indexes, card-specific provenance, and modal dismissal/scroll configuration. Lint and typecheck passed. The test setup uses the safe-area library’s official Jest mock because Jest does not emit native inset measurements.

Browser preview used the real components with synthetic fixtures at 393 × 852 (temporary preview route removed afterwards). Collapsed content measured 560px; expanded content measured 798px in a 709px viewport and reached its final action at scrollTop 89. Header remained visible. No live family data was modified. Screenshots: [Selected idea](gifts-selected-idea.png), [Expanded list at bottom](gifts-expanded-bottom.png). This verifies web layout, not native iPhone insets; device UAT is still needed.
